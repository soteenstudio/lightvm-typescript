# LightVM TypeScript

This template is created to make it easier for developers when first starting to use [LightVM](https://github.com/soteenstudio/lightvm).

 - **[Official Documentation](https://lightvm.vercel.app)**

## Usage
Before running any commands, make sure you have installed all necessary dependencies required by this project:

 - Install all required dependencies first:
    ```bash
    npm install
    ```

 - Command for **debug build**:
    ```bash
    npm run dev
    ```

 - Command for **production build**:
    ```bash
    npm run build
    ```

 - Command for **type checking**:
    ```baah
    npm run typecheck
    ```

 - Command for **linting**:
    ```bash
    npm run lint
    ```

 - Command for **formatting**:
    ```bash
    npm run format
    ```

 - Command for **testing**:
    ```bash
    npm run tests
    ```

> *Happy climbing!* 🚀
